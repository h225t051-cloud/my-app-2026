# TabiPlan - 旅行計画アプリ

GitHub Pagesで公開可能な、シンプルで美しい旅行計画アプリ。

## 機能
- スケジュール管理（日別のアクティビティ追加・編集・削除）
- 予算管理
- ブラウザへの自動保存 (localStorage)

## 公開方法 (GitHub Pages)
1. このリポジトリをGitHubにプッシュします。
2. GitHubリポジトリの **Settings** > **Pages** に移動します。
3. **Build and deployment** > **Branch** で `main` ブランチを選択して保存します。
4. 数分後、`https://<your-username>.github.io/<repo-name>/` でアプリが公開されます。
