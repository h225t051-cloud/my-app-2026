# TabiPlan - 旅行計画アプリ

GitHub Pagesで公開可能な、シンプルで美しい旅行計画アプリ。

## 公開URL
[https://h225t051-cloud.github.io/my-app-2026/](https://h225t051-cloud.github.io/my-app-2026/)

## ユーザーマニュアル

### 1. 旅行の基本設定
- **タイトルの変更**: ヘッダー下の旅行タイトル（例：「北海道 4泊5日の旅」）をクリックすると、新しいタイトルを入力できます。
- **予算の設定**: 右上の「予算」の金額をクリックすると、今回の旅行の総予算を数値で設定できます。

### 2. スケジュールの管理
- **日程の切り替え**: 左側のサイドバー（スマホでは上部）から「1日目」「2日目」などのタブをクリックして、その日の予定を表示します。
- **予定の追加**: 「スケジュール」セクションの右上にある「追加」ボタンをクリックし、タイトルと時間（例: 12:30）を入力します。
- **予定の編集**: 各予定カードの右側にある「編集（鉛筆アイコン）」ボタンでタイトルを変更できます。
- **予定の削除**: 各予定カードの右側にある「削除（ゴミ箱アイコン）」ボタンで予定を削除できます。

### 3. データの保存について
- 入力した内容はすべてブラウザの `localStorage` に自動的に保存されます。
- ブラウザを閉じたり再読み込みしたりしても、データは保持されます。
- **注意**: ブラウザのキャッシュをクリアするとデータが削除されるため、ご注意ください。

## 公開方法 (GitHub Pages)
1. このリポジトリをGitHubにプッシュします。
2. GitHubリポジトリの **Settings** > **Pages** に移動します。
3. **Build and deployment** > **Branch** で `main` ブランチを選択して保存します。
4. 数分後、上記の公開URLでアプリが利用可能になります。
